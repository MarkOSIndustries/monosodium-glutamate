# pqt
A CLI for reading and writing parquet files

## To Use
To clone and run this you'll need [Git](https://git-scm.com), [Java 25](http://openjdk.java.net/install/), and [Gradle](https://gradle.org/install/) installed on your computer.

```bash
# Clone this repository
git clone https://github.com/markosindustries/monosodium-glutamate
# Go into the repository
cd monosodium-glutamate/parquet
# Install dependencies
gradle build
# Run the app
java -jar build/install/pqt/pqt*.jar
```
